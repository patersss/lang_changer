# Capsy — переключение раскладки по Caps Lock

Нажатие Caps Lock переключает язык. Сам капс при этом **не включается**: нажатие
поглощается на уровне низкоуровневого хука, поэтому нет ни задержки, ни моргания,
ни залипшего капса.

Shift+Caps Lock работает как обычный Caps Lock.

Сейчас поддерживается Windows 10/11, архитектура готова к добавлению Linux и macOS.

## Как это работает

Две независимые части.

**Перехват клавиши.** Свой хук `WH_KEYBOARD_LL` через JNA. Ключевое отличие от
обычных Java-библиотек перехвата — возможность вернуть из обработчика `1` и тем
самым поглотить событие, чтобы Windows его вообще не увидела. Именно поэтому
Caps Lock не переключается и не требуется гасить его постфактум.

**Смена раскладки.** Системное сообщение `WM_INPUTLANGCHANGEREQUEST`, отправленное
окну в фокусе. Никакого синтетического ввода — переключение занимает единицы
миллисекунд. Часть приложений (Electron, UWP, некоторые Qt) это сообщение
игнорирует, для них остаётся запасной путь — эмуляция системной горячей клавиши.
Стратегии перебираются по очереди, и успех проверяется сравнением раскладки
потока до и после, а не тем, «отправилось ли событие».

## Права администратора

Windows не даёт процессу с обычными правами ни перехватывать клавиши, уходящие в
окно с более высоким уровнем целостности, ни отправлять ему сообщения — это UIPI.
Без повышения прав переключение **молча не работает** поверх:

- консоли, запущенной от администратора;
- диспетчера задач;
- редактора реестра и части системных окон;
- диалогов UAC.

Приложение определяет свой уровень прав при запуске: если повышения нет, в лог
уходит предупреждение, а пункт «О программе» в трее показывает об этом заметку.

Обычный ярлык в автозагрузке проблему не решает — он запускает процесс без
повышения. Рабочий способ — запланированная задача с наивысшими правами, она же
не показывает запрос UAC при каждом входе в систему:

```powershell
# PowerShell от имени администратора
powershell -ExecutionPolicy Bypass -File tools\install-autostart-admin.ps1
```

Убрать:

```powershell
powershell -ExecutionPolicy Bypass -File tools\install-autostart-admin.ps1 -Remove
```

Если Capsy установлен не в каталог по умолчанию, путь задаётся явно:

```powershell
... -File tools\install-autostart-admin.ps1 -ExePath 'C:\путь\к\Capsy.exe'
```

### Чего не покрывает и повышение прав

Экран входа, экран блокировки и рабочий стол UAC — отдельные защищённые рабочие
столы, туда не попадает ни один пользовательский процесс. Это ограничение
Windows, а не приложения.

## Сборка

```
mvn package
```

Получится `target/change_lang.jar`. Запуск:

```
java --enable-native-access=ALL-UNNAMED -jar target/change_lang.jar
```

Установщик собирается в CI через `jpackage` при пуше тега `v*`.

## Структура

```
core/       платформенно-независимые интерфейсы: LayoutSwitcher, KeyboardHook, AppPaths
platform/   выбор реализации под текущую ОС
  windows/  весь Win32-код: хук, стратегии переключения, коды клавиш
hooks/      обработчик Caps Lock: решает, поглощать ли клавишу
ui/         трей и защита от второго экземпляра
```

Добавление новой ОС — это новый пакет в `platform/` и одна строка в
`PlatformDetector`. Ничего за пределами `platform/` менять не нужно.
